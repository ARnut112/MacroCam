# MacroCam

เว็บไซต์ร้านกล้อง เลนส์ แฟลช ไฟ ขาตั้ง และอุปกรณ์เสริม ภาษาไทย รองรับสินค้ามือหนึ่งและมือสอง พร้อมหน้าสินค้า ตะกร้า รายการที่บันทึกไว้ สั่งซื้อโดยไม่สมัครสมาชิก แนบสลิป ติดตามคำสั่งซื้อ และหลังร้านสำหรับเจ้าของร้าน

**สถานะปัจจุบัน: เว็บไซต์ตัวอย่างในเครื่อง ยังไม่เปิดขายจริง ยังไม่เผยแพร่ และยังไม่ได้รันฐานข้อมูล Supabase** ข้อมูลสินค้า 14 รายการ ราคา สต็อก สภาพ และเงื่อนไขรับประกันเป็นข้อมูลสาธิต ต้องให้ร้านยืนยันและแทนที่ก่อนรับเงิน

## เปิดดูในเครื่อง

ใช้ Node.js 20.9 ขึ้นไป เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์แล้วรัน:

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000) หากมี `.env.local` อยู่แล้วให้แก้ไฟล์เดิมโดยไม่คัดลอกทับ แอปใช้เซิร์ฟเวอร์ Next.js/Node.js ต้องเปิดผ่านที่อยู่พรีวิวข้างต้น

ปล่อยคีย์ Supabase ว่างไว้เพื่อใช้โหมดตัวอย่าง ตะกร้า รายการที่บันทึกไว้ และคำสั่งซื้อจำลองเก็บใน `localStorage` ของเบราว์เซอร์นั้นเท่านั้น ข้อมูลไม่ได้ส่งให้ร้านและไม่ใช้ร่วมกันระหว่างเครื่อง การแนบสลิปในโหมดนี้สาธิตการเปลี่ยนสถานะโดยไม่อัปโหลดไฟล์จริง ใช้ชื่อ ที่อยู่ และเบอร์โทรสมมติในการทดลอง

หลังร้านที่ `/admin` เป็นตัวอย่างอ่านอย่างเดียวเมื่อยังไม่เชื่อมฐานข้อมูล ไม่มีบัญชีหรือรหัสผ่านผู้ดูแลจำลอง การจัดการข้อมูลจริงต้องผ่าน Supabase Auth และมี UUID อยู่ใน `admin_users`

## เชื่อมระบบจริงเมื่อร้านพร้อม

1. สร้าง **Supabase โปรเจกต์ใหม่สำหรับ MacroCam** แยกจาก Bakkabook ทั้งฐานข้อมูล คีย์ ผู้ดูแล และพื้นที่เก็บไฟล์
2. ทำตาม [คู่มือ Supabase](supabase/README.md) โดยรัน `supabase/migrations/202610150001_macrocam.sql` ครั้งเดียวในโปรเจกต์ใหม่นั้น แล้วสร้างบัญชีเจ้าของร้านและเพิ่มสิทธิ์ผู้ดูแลตามคู่มือ
3. ตั้งค่าตัวแปรจาก [.env.example](.env.example) ใน `.env.local` สำหรับเครื่องพัฒนา หรือใน Environment Variables ของโครงการโฮสต์สำหรับระบบจริง
4. เพิ่มรายการสินค้าและภาพสินค้าจริงผ่านหลังร้าน ตรวจสภาพ ผลทดสอบ ตำหนิ อุปกรณ์ในชุด ราคา สต็อก และประกันให้ตรงกับสินค้าชิ้นที่จำหน่าย
5. ใส่ QR รับเงินจริงแบบลูกค้ากรอกยอดเอง พร้อมชื่อบัญชี ธนาคาร และเลขบัญชีที่เจ้าของร้านยืนยัน ให้ร้านยืนยันนโยบายจัดส่ง คืนสินค้า ประกัน และข้อมูลส่วนบุคคลครบทั้ง 4 ส่วน
6. ตรวจตาม [รายการทดสอบ](docs/TESTING.md) กับฐานข้อมูลทดสอบก่อน แล้วจึงตั้ง `STORE_CHECKOUT_ENABLED=true` เมื่อต้องการเปิดรับคำสั่งซื้อจริง

การใส่คีย์ Supabase ครบจะเปลี่ยนไปอ่านสินค้าจากฐานข้อมูลจริงทันที โดยไม่คัดลอกสินค้าตัวอย่างเข้าไปให้อัตโนมัติ API รับคำสั่งซื้อยังปิดอยู่จนกว่าจะเปิด flag โดยตรง และฐานข้อมูลตรวจซ้ำว่ามี QR บัญชีรับเงิน และนโยบายครบ การตรวจความถูกต้องของบัญชีหรือเนื้อหานโยบายยังเป็นหน้าที่เจ้าของร้าน

| ตัวแปร                          | ค่าที่ต้องใช้                                                                         |
| ------------------------------- | ------------------------------------------------------------------------------------- |
| `NEXT_PUBLIC_SUPABASE_URL`      | URL ของโปรเจกต์ MacroCam ใหม่                                                         |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | anon key ของโปรเจกต์เดียวกัน                                                          |
| `SUPABASE_SERVICE_ROLE_KEY`     | service role key; เก็บฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามเติม `NEXT_PUBLIC_`                 |
| `NEXT_PUBLIC_SITE_URL`          | `http://localhost:3000` ในเครื่อง; ตั้งเป็น origin HTTPS จริงเมื่อเผยแพร่             |
| `CRON_SECRET`                   | ค่าสุ่มลับอย่างน้อย 32 ตัวอักษรสำหรับงานหมดอายุ                                       |
| `ORDER_ACCESS_SECRET`           | ค่าสุ่มลับอย่างน้อย 32 ตัวอักษรสำหรับลงลายเซ็นสิทธิ์คำสั่งซื้อ                        |
| `TRUST_PROXY_HEADERS`           | เริ่มที่ `false`; เปิดเฉพาะเมื่อ proxy เขียน `x-forwarded-for` ทับเองอย่างเชื่อถือได้ |
| `STORE_CHECKOUT_ENABLED`        | เริ่มที่ `false`; ตั้ง `true` หลังเตรียมข้อมูลและทดสอบระบบจริงครบ                     |

คีย์ลับต้องอยู่ใน Environment Variables หรือ `.env.local` เท่านั้น ไฟล์ `.env.local` ถูกยกเว้นจาก Git แล้ว Vercel ใช้ header ของแพลตฟอร์มสำหรับจำกัดความถี่โดยอัตโนมัติ จึงไม่จำเป็นต้องเปิด `TRUST_PROXY_HEADERS` เพิ่ม

## คำสั่งซื้อหมดอายุภายใน 1 ชั่วโมง

เจ้าของร้านยืนยันเวลา **1 ชั่วโมง** สำหรับคำสั่งซื้อที่ยังไม่ส่งสลิป ระบบจริงจองสต็อกใน transaction ตอนสร้างรายการ และตั้ง `expires_at` เป็นเวลาสร้างบวก 60 นาที เมื่อหมดเวลา แนบสลิปต่อไม่ได้และคืนสต็อกครั้งเดียว รายการที่ส่งสลิปทันเวลาจะรอร้านตรวจเองและไม่หมดอายุด้วยกฎนี้

คำขอสร้าง/ติดตามคำสั่งซื้อและอ่านรายการหลังร้านช่วยจัดการรายการที่เกินเวลา หากต้องการคืนสต็อกแม้ไม่มีคนเปิดเว็บ ให้ตั้งงานเรียก `/api/cron/expire-orders` ทุก 1 นาที พร้อม header `Authorization: Bearer <CRON_SECRET>` หรือใช้ตัวตั้งเวลาที่เชื่อถือได้เรียก `select public.expire_orders();` งานหนึ่งครั้งจัดการสูงสุด 500 รายการ การคืนสต็อกจึงเกิดหลังพ้นกำหนดในรอบทำงานถัดไป

Migration ยังไม่ติดตั้งหรือเปิดงานตั้งเวลาให้ `runtime_config.scheduled_expiry_enabled` เป็นเพียงตัวบันทึกสถานะ ให้ตั้งเป็น `true` หลังตรวจว่างานเรียกสำเร็จแล้ว ตาม [คู่มือฐานข้อมูล](supabase/README.md) ปัจจุบันยังไม่มีงานดังกล่าวทำงานอยู่

## เตรียมเผยแพร่บน Vercel

สร้างโครงการ Vercel ใหม่สำหรับ MacroCam ใช้โฟลเดอร์นี้เป็นรากและเลือก Next.js ใส่ตัวแปรให้ตรงกับสภาพแวดล้อม Preview/Production รวมถึง `NEXT_PUBLIC_SITE_URL` ของ origin นั้น จากนั้นตรวจ build, ระบบฐานข้อมูล และรายการทดสอบก่อนเปิด checkout ต้องจัดเตรียมตัวตั้งเวลาตามเงื่อนไข 1 ชั่วโมงด้วย ยังไม่มีการสร้างโครงการหรือ deploy จากงานนี้

แอปมี API และระบบหลังร้าน จึงต้องใช้โฮสต์ที่รัน Next.js ฝั่งเซิร์ฟเวอร์ได้ การส่งออกเป็นเว็บไฟล์นิ่งอย่างเดียวไม่รองรับขั้นตอนสั่งซื้อจริง

## ตรวจและปรับต่อ

```powershell
npm run typecheck
npm test
npm run build
npm run start
```

ผลที่รันแล้วและขั้นตอนที่ยังต้องตรวจอยู่ใน [docs/TESTING.md](docs/TESTING.md) การแนบสลิปยังไม่ถือว่าจ่ายสำเร็จ ร้านต้องตรวจยอดเอง ไม่มี AI ตรวจสลิปหรือการเชื่อมต่อ LINE

หลังเปิดเซิร์ฟเวอร์ตัวอย่าง ตรวจ HTML และการปฏิเสธคำขอที่ไม่มีสิทธิ์ได้ด้วย `npm run test:smoke` โดยไม่อัปโหลดหรือสร้างรายการจริง จัดรูปแบบโค้ดด้วย `npm run format` ได้ ภาพและแนวทางออกแบบบันทึกไว้ใน [docs/DESIGN.md](docs/DESIGN.md)

ไฟล์ `index.html` เป็นทางเข้าพรีวิวสำหรับ Laragon ในเครื่อง ส่วนเว็บใช้งานจริงอยู่ใน `app/` และรันด้วย Next.js

ภาพประกอบสินค้าเก็บใน `public/images/products` พร้อม [เครดิตภาพ](public/images/SOURCES.md) ฟอนต์ไทยเก็บใน `public/fonts` พร้อมใบอนุญาต ภาพรุ่นสินค้าอาจแสดงเลนส์หรืออุปกรณ์ที่ไม่ได้อยู่ในชุดขาย ร้านต้องยืนยันรายการในชุดและใช้ภาพสินค้าจริงก่อนเปิดขาย
