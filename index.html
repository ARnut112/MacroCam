เปิดร้าน MacroCam

หากยังเปิดร้านไม่ได้ ให้เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์ npm run dev จากนั้นกดปุ่มด้านบนอีกครั้ง

ไฟล์นี้เป็นทางเข้าสำหรับ Laragon ในเครื่องเท่านั้น คู่มือเปิดใช้งานและตั้งค่าฐานข้อมูลอยู่ใน README.md
